# Developer Style Guide

This document explains how to run local formatting/linting and the outputs policy.

## Code Formatting and Linting

We use **Black** (formatter) and **Ruff** (linter) locally. No CI enforcement yet.

### Installation

```bash
# Activate your virtual environment first
source dev_env/bin/activate

# Install dev tools
pip install black ruff
```

### Running the tools

```bash
# Format all Python files
black src/ tests/

# Check formatting without changing files
black --check src/ tests/

# Lint all Python files
ruff check src/ tests/

# Auto-fix safe lint issues
ruff check --fix src/ tests/
```

### Configuration

All settings are in `pyproject.toml`. Key choices:
- Line length: 100 characters
- Import sorting: enabled (via Ruff's `I` rules)
- Target Python: 3.10+

## Outputs Policy

| Directory   | Git Status      | Purpose                                      |
|-------------|-----------------|----------------------------------------------|
| `outputs/`  | **Untracked**   | Generated artifacts (plots, pickles, logs)   |
| `results/`  | **Committed**   | Publication-ready results, curated outputs   |

### What goes where

- **`outputs/`**: anything generated by running analyses
  - `outputs/bifurcation/` — bifurcation analysis plots and data
  - `outputs/stability/` — stability analysis outputs
  - `outputs/descriptive/` — descriptive statistics plots
  
- **`results/`**: only curated, final outputs you want to keep
  - Figures for papers
  - Summary tables
  - Manually reviewed and approved results

### Metadata requirements

Every saved artifact should include:
- Random seed used
- Package version
- Key parameters (preset stage, grid size, etc.)
- Timestamp

Use `save_with_version()` from `src/analysis/common.py`:

```python
from src.analysis.common import save_with_version

save_with_version(my_data, 'outputs/bifurcation/my_results.pkl')
```
